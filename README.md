# Order API

Простой REST API для управления заказами, написанный на Go (`net/http`, без фреймворков).
Данные хранятся в памяти (map), без базы данных — учебный проект для отработки HTTP, JSON и конкурентности в Go.

## Возможности

- `POST /orders` — создать заказ
- `GET /orders` — получить список всех заказов
- `GET /orders/{id}` — получить заказ по id
- `DELETE /orders/{id}` — удалить заказ по id

## Технологии и приёмы

- `net/http` — маршрутизация с указанием метода прямо в пути (Go 1.22+)
- `encoding/json` — декодирование и кодирование JSON
- `sync.Mutex` — защита общего состояния (map с заказами) от гонки данных при параллельных запросах
- path-параметры (`{id}`) и обработка ошибок с корректными HTTP-статусами (400, 404, 405)

## Запуск

```bash
go run main.go
```

Сервер стартует на `http://localhost:8080`.

## Примеры запросов

Создать заказ:
```bash
curl -X POST http://localhost:8080/orders -d '{"product":"Ноутбук","quantity":2}'
```

Получить список всех заказов:
```bash
curl http://localhost:8080/orders
```

Получить заказ по id:
```bash
curl http://localhost:8080/orders/1
```

Удалить заказ по id:
```bash
curl -X DELETE http://localhost:8080/orders/1
```

## Требования

Go 1.22 или новее (используется современный синтаксис маршрутизации с методом и path-параметрами).
